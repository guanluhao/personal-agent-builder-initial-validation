# Personal Agent Builder初步验证

[GitHub 公开仓库](https://github.com/guanluhao/personal-agent-builder-initial-validation)。

这是《大模型智能体驾驭工程》课程项目的公开初步验证版。使用者导入自己的 Python 程序后，构建器先分析源码并说明程序能做什么；确认功能范围后生成可独立运行的个人智能体。智能体通过本机已登录的官方 Codex 命令行理解日常提问，并调用已确认的 Python 功能。新功能先在隔离副本中修改和测试，确认后才启用。

## 当前成果

- 本地图形界面：导入单个 `.py` 文件、文件夹或压缩包，查看项目能力说明，确认并生成智能体，再与它对话。
- 通用生成流程：依据当次导入的源码和候选命令入口生成工具；表格处理和二维成像是验证案例，不是按项目名称写死的分支。
- 可复查的升级流程：在副本里准备修改、运行新旧功能检查、展示差异、确认启用及回退。
- 两类真实案例：CSV 数值列处理和二维模型/观测系统预览；独立的示例智能体、自动测试及验证记录在仓库中。

这些能力仍是课程阶段的原型。任意复杂 Python 项目的一键适配、完整操作系统沙箱、完整二维正演及 RTM 未经验证，不能视为已支持。详细边界见 [完成度](docs/completion.md) 与 [变更记录](docs/changes.md)。

## 在 Windows 上开始

1. 安装 Python 3.10 或更新版本，运行 `setup_environment.cmd` 准备项目环境。
2. 双击 `start_app.vbs` 打开本机界面。软件初始不预装示例智能体。
3. 导入自己的 `.py` 文件、Python 项目文件夹或 ZIP；查看软件生成的能力说明，选定范围后创建。
4. 日常语言对话使用本机已登录的官方 Codex CLI。此仓库不包含账号、API Key 或订阅凭据；ChatGPT 订阅不等于通用 API 额度。

当前电脑上的更详细操作见 [图形界面使用指南](docs/user-guide.md)。命令行备用入口为 `python -m personal_agent_builder.webapp`。运行测试可使用 `python -m pytest -q`。

## 文件位置

- `personal_agent_builder/`：构建器、运行器及网页界面源码。
- `agents/`：已经生成并保存的课程示例智能体。
- `examples/`：表格及二维项目验证材料。
- `tests/`：自动测试。
- `docs/`：架构、研究、操作、变更和课程交付记录，从 [文档索引](docs/README.md) 开始。
- `course-video/`：最终演示和字幕；[素材说明](course-video/README.md)。

## 安全与公开范围

导入分析阶段仅读取副本；确认后执行经过限制的已登记功能。当前运行器没有系统级隔离，面对不可信程序仍应使用额外沙箱。公开视频仓库只收录可发布的课程成果；本机凭据、虚拟环境、临时导入副本、个人聊天截图和原始录屏不在仓库内。具体清单见 [公开发布说明](docs/publication.md)。
