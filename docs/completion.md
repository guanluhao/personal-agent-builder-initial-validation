# 完成度与剩余工作

## 2026-10-16 图形界面进展

Builder 现可通过 `start_app.vbs` 打开本地浏览器界面。首次界面为空，不预设项目；可选择文件夹或 ZIP，先只读分析，再由用户勾选简单 `argparse` 候选并确认测试，随后在聊天区自然语言调用生成的 Agent。已实际用界面从 CSV 和二维 V1 两个材料生成 Agent：CSV 的中文请求返回三行、总和 10 和 JSON 文件；二维预览生成 4 PNG 与 4 SVG。详情见 [图形界面计划](gui-plan.md)、[使用指南](user-guide.md)与 [变更记录](changes.md)。

当前仍不能声称任意复杂 Python 项目都能一键生成可运行 Agent。对于无简单命令入口、缺少依赖、非 JSON 输出或高成本功能，界面会保留分析和失败状态，需要后续适配。项目代码执行没有操作系统级沙箱，确认前仅读取，确认后仅运行已选副本入口。

## 现在已经能做什么

1. Builder 对一个本地 Python 项目做只读扫描，输出源码、入口、依赖线索和中文《项目能力说明》；简单 `argparse` 入口还能自动列出工具候选与参数。静态推断明确标注为未运行验证。
2. 用户审阅能力清单并确认摘要后，Builder 生成可独立启动的 Agent 目录，包含项目副本、自然语言终端、MCP Tools/Resource/Prompt、输入输出校验和调用记录。
3. 本机已有官方 Codex CLI 的 ChatGPT 登录，自由语言请求可映射到已批准工具；直接使用工具名和参数无需大模型服务。本项目未申请或保存 API Key，也不把 ChatGPT 订阅当成通用 API 额度。
4. 已保存 CSV、早期二维 V1 和新米制二维 V1 三个正式示例 Agent，均真实调用过 Python。新二维 Agent 已按自然语言把密度异常左移 5 米、下移 4 米；独立二维隧道示意配置延长 10 米，并重新绘图。原科研仓库未改，完整正演和 RTM 未运行。
5. 未注册的新需求会写入升级请求。隔离暂存、测试、精确版本批准、启用和回退组件已在小型 CSV 测试夹具中验证。
6. 已准备可双击启动的本地浏览器界面、[Windows 使用指南](user-guide.md)和[新版视频文案草稿](video-narration-draft.md)。先前渲染过的视频因用户不认可配音与画面对应，仍是历史草稿；新版文案待用户修改确认后再制作配音与成片。

## 为什么还不能称为任意项目全自动完成

- 对任意新项目，工具清单仍需要人工核查入口、参数、结果和副作用。简单命令入口可自动发现，但 Builder 尚不会从一份源码可靠地自动生成完整安全 Schema。
- 升级组件能隔离、测试、批准和回退明确的代码改动，但还没有通用的自然语言自动修复任意 Python 项目能力。二维 V1 的 PDF 候选已按用户决定从交付范围移除。
- 当前运行器没有操作系统级沙箱。导入不可信源码时只读分析是安全边界；要执行未审查代码，应先使用容器或受限账户。
- 新 GitHub 仓库已经建立并上传，已核验 `Private` 和默认分支 `main`；本地源码及测试当前可用。没有运行完整二维正演、RTM 或科研精度验证。
