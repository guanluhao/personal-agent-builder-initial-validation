## 用到本项目的视频设计

- 开头在真实空白 Builder 画面上提出具体问题，例如“说一句话，能让旧 Python 程序自己出图、继续改图吗？”随后尽快进入导入项目操作。此标题是后期说明文字，不冒充软件输出。
- 章节卡片用用户能理解的结果作标题：“先看懂程序”“确认后才生成”“一句话汇总表格”“移动异常点并重新出图”。每张卡片尽量短，主体时间留给真实界面和前后图片。
- CSV 部分展示真实对话、三行数据、总和 10 和 JSON 文件；二维部分展示真实模型图、观测系统图，以及异常点和隧道前后对比。画面与对应旁白同时出现。
- 结尾只保留已讨论的两层未来方向：新需求驱动程序修改与 Agent 升级；更远处从单独的用户需求规划并生成 Agent。两项都标为未来方向。
