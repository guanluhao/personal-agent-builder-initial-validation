# Personal Agent Builder 图形界面使用指南

**重新导入时会重新分析：** 无论导入单个程序文件还是多文件项目，工作台会阅读这次上传的源码并调用本机语言模型整理说明。项目自带的说明文件只是参考；若与程序不符，以代码和实际运行结果为准。左侧已存在的智能体来自以前的创建记录，不会作为新项目的模板。查看待确认的程序升级时，即使关闭并重新打开本机页面，打开对应智能体也能恢复最近一次通过测试、尚未启用的方案。

**本机界面更新：** 导入并选好功能后，写清楚希望智能体帮你做什么，点“讨论我的使用方式”。如果程序信息足够，软件会直接整理可核对的创建方案；确实缺少关键决定时才问一个问题。核对并确认后才会正式创建。对已有智能体说“其他按项目默认配置”时，软件会先查现有配置，准备修改后把采用的设置和测试结果列出来。切换左侧智能体后，本次页面里的对话、结果、输入草稿和待添加文件会各自保留；刷新或重开页面可看到最近十轮简短问答。

## 打开软件

在当前电脑双击项目根目录的 **`start_app.vbs`**。它会在浏览器打开一个仅绑定本机 `127.0.0.1` 的界面，没有公网地址，也不会弹出终端窗口。第一次打开时，“我的 Agent”为空；二维和 CSV 都不是预先选好的项目。关闭时点击界面右上角“关闭应用”。

如果换电脑，先安装 Python 3.10+，双击 `setup_environment.cmd` 准备环境，然后再打开 `start_app.vbs`。当前电脑已经完成环境准备，且官方 Codex CLI 已通过 ChatGPT 登录；无需填写 API Key。新电脑要使用自由语言时，需要在那台电脑按官方方式登录 Codex。

## 从你的程序生成 Agent

1. 将**单个 `.py` 文件、Python 项目文件夹或 ZIP**拖到中央导入区，也可以分别点击“选择程序文件”“选择文件夹”“选择压缩包”。界面只把受支持的小文件复制到本机导入区，不会运行项目安装脚本。
2. 等待《项目能力说明》。它只回答三件事：**这个项目能做什么、你可以怎样提问、最后会得到什么结果**。例句仅供参考；此时只读过程序，尚未实际运行。
3. 下方会显示从程序中找到的功能。勾选你想要的功能，在“希望这个智能体怎样帮你”里用自己的话描述日常用途，点击“讨论我的使用方式”。软件会先尝试直接整理创建方案；确有关键缺口时只问一个问题。核对方案后再勾选确认并创建。**确认前不会运行导入的 Python 代码。**如果手头已有测试文件，可展开“如果现在有测试资料”并填写；没有资料也能创建，页面会把初次测试标为“尚未试运行”。创建时的测试文件和列名不会固定为以后每次调用的默认值。
4. 页面切到智能体聊天区。每次需要处理新资料，可点“添加本次文件”或把小型数据文件拖入聊天区，然后直接说明这次要做什么。使用同一个智能体处理下一份文件，**不需要重新导入程序或重新创建**。模型会根据本次文件、程序实际能力和当前对话决定调用、解释、追问或提出升级；追问后只需回答，软件会保留这次添加的文件。只有真实运行成功且结果核查通过的任务才算已验证。没有登录或暂时无法连接时，页面会明确提示未完成。
   如果智能体问“要统计哪一列？”，下一条直接答“刚才那份文件的压力列”即可。继续修改模型时，也可说“再向左移动两米，其他方向不动”，它会参考最近的对话和同一类模型的上次配置；如果“它”可能指多个对象，仍会追问。最近十轮简短问答只保存在这个智能体的本机目录，重新打开能看到；删除智能体时会一起删除。完整数据文件和完整程序输出不会复制进聊天记录。
5. 点击“导入另一份程序”可以从空白导入区重新开始。你自己生成的智能体会保存在左侧“我的智能体”，下次打开仍可使用。其旁边的“删除”按钮会清除该智能体及其本机对话、结果文件，原始程序不受影响。压缩包内若直接放项目文件，智能体名称会采用压缩包文件名。已生成目录位于本机 `artifacts/web_builder/agents/`，其中含独立运行文件、功能接口和项目副本；原项目不会被覆盖。

## 让智能体学会新功能

1. 在对话里用平常的话提出新需求，例如“给表格新增一列实验值，依次填入 7、352、789”。如果信息不够，例如没有说新列名称，智能体会先请你补充。
2. 如果当前程序尚未支持这项需求，构建器会自动在智能体自己的程序副本中准备并检查新功能；不会修改导入前的原程序，也不会立即启用。准备失败时可点“重试准备升级”。
3. 等待实际测试，查看“新功能已在副本中测试通过”、原有功能复查结果，并展开“查看程序修改内容”。测试失败时不能启用。
4. 核对无误后点 **“确认并启用这项升级”**。之后可以继续用自然语言让智能体调用新功能。想恢复时点智能体页面的 **“恢复上一个版本”**。

目前自动升级能为入口清晰的项目增加一个简单命令功能，也可同时修改最多四个已有 Python 文件。对复杂修改、需要新依赖或高成本计算的项目，仍可能无法自动生成可验证的方案。生成的程序只在副本中测试，但当前没有操作系统级隔离，请只对信任的项目使用。

这套流程按你导入的程序内容工作，不是分别为下方两个案例编写的智能体。已用另一份临时文本程序验证同一生成和执行流程。若程序没有清楚的命令入口，软件可能只能给出说明，不能立刻生成可运行的功能；此时不要把候选说明当成测试通过。

只上传一个陌生 `.py` 文件时，软件会让本机已登录的 Codex 根据源码说明用途。若能找到适合封装的函数，会在导入副本准备调用入口供你确认；确认前不运行原文件。若代码导入时就会执行工作、缺少依赖或没有合适的函数，软件可能只能说明用途，无法保证生成可运行的智能体。可先阅读说明，再决定是否确认试运行。

例如只选择 `csv_task.py`：阅读说明、选择功能、描述你想怎样使用它，回答软件提出的问题并确认创建。进入聊天区后，添加任意一份符合该程序要求的表格并说“帮我统计这份数据”。如果列名或统计目标不清楚，软件会先问；回答后继续使用刚加的文件。下一次可以再添加另一份表格，列名无需与第一次相同。此示例原程序只支持有表头、逗号分隔、指定列为数字的表格，当前功能是统计记录数、总和和平均值。新增行列、复杂清洗或其他统计须先提出升级，经副本修改和测试、你确认后才能使用。一个文件最多 1 MB；聊天区不接受新的 `.py` 作为数据文件。

### 用自己制作的多份表格验收

只创建**一个**智能体，然后在它的聊天区依次添加不同的表格，不要再导入原程序。先试一份只有一列可统计数字的表格，再换列名和文件名；核对结果中的行数、总和与平均值是否与手算一致。接着试一份有两列以上数字、但不指明要统计哪列的表格：它应先询问，回答后仍使用刚添加的文件。最后可试原程序不支持的格式或新操作：界面应说明需要扩展功能，展示副本中的修改和测试，**只有你确认后**才启用。若程序报错或结果尚未核查，就不能把它记为成功。你制作的文件无需提前交给构建器开发，也不必使用示例表头。

## 创建后继续调整同一个智能体

打开左侧已经生成的智能体，直接在对话里说“以后先问我……”“结果先解释……”，或者点 **“调整这个智能体”** 描述希望改变的使用方式，例如开场如何提问、结果先解释什么、添加文件按钮叫什么。模型会判断这属于交互调整还是程序新功能：交互调整可先回答澄清问题、查看完整调整方案，再点 **“确认并应用调整”**；在确认前现有智能体不变。调整后可以继续用原来的智能体，原程序功能清单不变；点 **“撤销上次调整”** 可恢复之前的使用方式。需要新增计算、改输入格式或编辑结果文件等程序能力时，页面会让你在下方对话中发送该需求，按“准备修改→看差异与测试→确认启用”的流程处理。

如果语言服务暂时不可用或额度耗尽，调整请求会留在该智能体的本机记录中。以后再次打开这个智能体，输入框会保留这段话；服务恢复后点“讨论调整方式”继续。**保存请求不等于完成修改**，也不会绕过模型、测试或你的确认。创建前的讨论仍需语言服务；没有服务时不会把未讨论的方案伪称为已确认。

## 独立盲测

作业文件夹根目录有一份 `验收盲测程序.zip`。它没有被提前导入构建器，也没有预先生成智能体。最终验收时，你可以在空白工作台选择这个压缩包，先阅读软件给出的用途、示例指令和输出，再选择功能并亲自生成、提问。该小程序本身已经单独运行；它与构建器的集成结果需以你那次操作为准。

## 先用自带材料试一遍

- **表格案例：** 只导入 `examples/csv_project/csv_task.py`，按问答完成创建，然后在聊天区添加 `examples/csv_project/sample.csv`。同一智能体随后还可处理你自己制作的另一份表格，不要求沿用原来的文件名和列名。示例数据为 3 行、总和为 10；你提供的 `test.csv` 经真实调用得到 5 行、总和 168。
- **二维 V1：** 选择 `examples/seismic_v1_snapshot` 文件夹。更新后的报告会发现 `preview`、旧的网格索引 `move_anomaly`、新的 `shift_anomaly_meters` 与 `extend_tunnel` 候选。课程中的新自然语言案例可勾选 `preview`、`shift_anomaly_meters`、`extend_tunnel`，并在确认前为后两项测试填入 `left_m=5`、`down_m=4` 和 `meters=10`。生成后先说“把密度异常向左移动 5 米、向下移动 4 米”，再说“请生成模型图”；另一个独立示意配置可说“把隧道向右延长十米”，然后重新预览。原密度异常练习没有隧道，因此延长隧道使用单独的 `tunnel_config.json`。这些都是低成本配置修改和绘图，不运行完整正演或 RTM。

示例材料只是你可选的测试程序，**启动界面时不会自动加载**。本轮自动化演示产生的 Agent 已单独归档，初次打开仍显示空白状态。

## 当前能力边界

- 自动候选生成针对结构清晰的简单 `argparse` 命令。复杂项目可能只得到分析报告和“需要适配”提示；不会假装已生成可用 Agent。
- 现阶段工具测试要求命令输出 JSON 对象；每个项目的额外依赖需要事先在受控环境准备。输出通过校验表示接口及文件检查通过，不代表科研精度已验证。
- 项目代码视为不可信。当前运行器尚无操作系统级沙箱，所以只应确认你信任、计算成本可控的程序。新功能请求会登记；准备升级只改隔离副本，未经你核对测试结果并再次确认，不会启用升级。
- 每条聊天消息由本机已登录的官方 Codex 程序处理；界面示例不是匹配规则。ChatGPT 订阅不等于通用 API 额度，本项目不保存密钥。程序执行仍只限已确认的功能；添加新能力必须经过隔离测试和用户确认。
